# Xeque de Tinta

Roguelite de tabuleiro com batalhas de cartas em turnos, em pixel art. Um peão de madeira ganha vida e atravessa um tabuleiro encantado casa por casa, enfrentando monstros de tinta mágica até chegar ao Jogador, a mão que controla o jogo.

- **Engine:** Unity 6 (6000.4), 2D URP
- **Plataformas:** Windows e macOS
- **Autores:** Márcio Dias de Lima Filho e Tiago Augusto Dal'Acqua Gonçalves
- **Projeto:** disciplina de Desenvolvimento de Jogos, 2º bimestre, 2º semestre de 2026

## Como abrir

1. Instale o Unity 6000.4.10f1 pelo Unity Hub.
2. Clone o repositório e abra a pasta no Unity Hub (Add > Add project from disk).
3. Abra a cena `Assets/_Project/Scenes/Boot.unity` e aperte Play.
